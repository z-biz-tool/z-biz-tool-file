# 02 — 产品能力与交互优化

> **状态**：设计方案，未实现；基线 `b35d1a2`；当前事实 = 静态代码证据，指标 = 拟定验收目标

---

## 产品定位回顾

z-biz-tool-file 定位为"万能文件管理器"，聚合文件管理 + 媒体预览 + 全盘搜索 + 开发者工具。对标 macOS Finder 与 Double Commander 的交互理念，核心差异化在于**多格式预览深度**与**开发者工具集成**。

---

## 用户流程缺口分析

### 1. 目录树 / 列表导航

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| FileTree 侧边栏存在 | 无 lazy-load：大树展开时一次性加载所有子节点 | P1 |
| ColumnView（Finder 分栏）已实现 | 无面包屑 + 列预览联动（选中子项时右侧无内容预览） | P2 |
| 路径栏可编辑跳转 | 无路径自动补全/历史下拉 | P2 |
| 多标签页已实现（fileStore tabs） | Tab 不持久化，刷新丢失；openTab 不去重 | P1 |

**推荐改造**：
- FileTree 改为按需展开（展开时才 `list_directory` 子节点）
- Tab 状态用 `tauri-plugin-store` 持久化到 JSON；openTab 先查找已有同路径 tab
- 默认路径从 `dirs::home_dir()` 获取，移除硬编码

### 2. 搜索与过滤

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| 快速过滤（当前目录 subsequence 匹配） | 无正则/高级过滤（按日期范围、大小、类型组合） | P1 |
| `search_files` walkdir depth=5 | 深层目录漏检；无增量索引加速 | P1 |
| `full_disk_search` depth=8, max=200 | 结果硬截断，无分页加载更多 | P2 |
| `search_file_content` 纯子串匹配 | 无模糊匹配、无正则、无搜索历史 | P2 |

**推荐改造**：
- 后端引入 `ignore` crate（ripgrep 同款）实现 `.gitignore` 感知的递归遍历
- 搜索支持 `type:image date:>2024-01-01 size:>10MB` 过滤语法
- 索引器改为 SQLite FTS5 存储，支持增量更新

### 3. 批量选择与操作

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| Shift+Click 区间选择已实现 | 无"全选同类型"快捷操作 | P2 |
| 右键菜单含批量重命名/删除/哈希/OCR | 操作串行无进度条、无取消按钮 | **P0** |
| 粘贴（copy/move）逐个串行 | 大量文件时无并发、无进度、失败不回滚 | P1 |
| TransferQueue 组件存在 | 实际未与批量操作关联，仍为串行 invoke | P1 |

**推荐改造**：
- 后端新增 `batch_operation` 命令，接受操作类型 + 路径列表，返回 channel 上报进度
- 前端用 `tauri::Event` 监听进度百分比，展示 Progress + Cancel 按钮
- 取消通过 `CancellationToken`（tokio_util）实现，后端逐条检查

### 4. 重命名 / 移动 / 复制 / 删除

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| 重命名：单次 + 批量（带预览） | 批量重命名无 undo | P1 |
| 移动：rename 优先 → copy+delete fallback | 跨卷移动大文件无进度 | P1 |
| 复制：`copy_dir_recursive` 无进度报告 | 同名文件无冲突处理（覆盖/跳过/重命名） | P1 |
| 删除：默认走回收站 ✓ | 永久删除 `delete_file` 无路径安全校验（见 SEC-02） | **P0** |
| 回收站：完善的 trash 系统 ✓ | 无自动清理策略（如 30 天后自动永久删除） | P2 |

**推荐改造**：
- 所有文件操作前统一走 `validate_path()` 校验函数
- 复制/移动增加冲突策略参数：`overwrite | skip | rename_auto`
- 操作历史记录到 undo stack（最近 50 步），⌘+Z 撤销

### 5. 文件预览

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| 支持 image/video/audio/md/csv/json/yaml/pdf/epub/doc | EXIF 加载在 render 分支直接 invoke（每次渲染触发） | P1 |
| 图片编辑器（18+ 调整项） | 编辑后无"另存为"，只有原地保存 | P2 |
| 文本预览 10MB 限制 | 无分片加载大文件（>10MB 直接报错） | P2 |
| AI 摘要功能可用（ai_summarize_file） | 仅支持文本文件，图片/视频无 AI 描述 | P2 |
| 预览面板可拖拽调整宽度 | 无 QuickLook 式空格键快速预览 | P1 |

**推荐改造**：
- EXIF 加载移入 `useEffect` 避免重复请求
- 增加空格键 QuickLook 弹窗（macOS 原生交互）
- 大文本文件支持 Range 分片加载（前 1MB + 按需加载更多）

### 6. 收藏与历史

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| Bookmarks 组件存在，localStorage 持久化 | 无同步到 Tauri store（仅前端内存） | P2 |
| 历史导航（history 数组 + historyIndex） | 无持久化、无"最近访问文件"列表 | P1 |
| WorkspaceManager 可保存工作区 | 无"最近打开"全局入口 | P2 |

### 7. 拖拽

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| DragDropTarget 实现完整 | 拖拽移动串行 invoke，多文件无进度 | P1 |
| DropStack 暂存区存在 | 暂存栈不持久化 | P2 |
| 安全检查：阻止移入自身子目录 ✓ | 无从外部（Finder）拖入文件的处理 | P2 |

### 8. 快捷键

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| ⌘+C/X/V, ⌘+1-4, ⌘+Shift+Backspace | 无 ⌘+A 全选、⌘+Z 撤销、⌘+F 聚焦搜索 | P1 |
| useKeyboardShortcuts hook 存在 | 快捷键不可自定义 | P2 |

### 9. Agent / AI 辅助

| 当前状态 | 缺口 | 优先级 |
|----------|------|--------|
| ai_summarize_file + ai_chat 可用 | aiService.ts 调用的 8 个命令全未实现 | P1 |
| AgentManager.ts 为 SQL 存根 | 无文件管理 Agent（智能整理/分类/去重） | P2 |
| AI 配置面板存在（API Key/Provider） | 无本地模型 fallback（离线不可用） | P2 |

**推荐改造**：
- 清理 aiService.ts 中未实现命令的调用，或补齐后端实现
- AgentManager 重写为 FileAgent：接受自然语言指令 → 生成操作计划 → **用户确认后才执行**
- Agent 绝不可自动执行删除/移动等破坏性操作（核心原则）

## 交互优化优先排序

| 序号 | 改造项 | 影响面 | 工作量 | 优先级 |
|------|--------|--------|--------|--------|
| 1 | 批量操作进度条 + 取消 | 所有多选操作 | 中 | P0 |
| 2 | 删除路径安全校验 | 数据安全 | 小 | P0 |
| 3 | Tab 持久化 + 去重 | 日常导航 | 小 | P1 |
| 4 | 默认路径动态获取 | 首次体验 | 极小 | P1 |
| 5 | 空格键 QuickLook | 预览效率 | 中 | P1 |
| 6 | 搜索高级过滤语法 | 查找效率 | 大 | P1 |
| 7 | 复制/移动冲突策略 | 数据完整性 | 中 | P1 |
| 8 | ⌘+A/Z/F 快捷键补全 | 操作效率 | 小 | P1 |
| 9 | FileTree lazy-load | 大项目性能 | 中 | P1 |
| 10 | EXIF 加载去重 | 预览性能 | 极小 | P1 |
| 11 | Undo stack（最近 50 步） | 容错能力 | 大 | P1 |
| 12 | 回收站自动清理 | 磁盘空间 | 小 | P2 |

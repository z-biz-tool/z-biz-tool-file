## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| CSP 启用后 asset:// 协议加载媒体失败 | 预览功能不可用 | 先在 dev 环境验证 CSP 策略 |
| execute_command 移除后内置终端不工作 | 终端功能缺失 | 同步迁移到 tauri-plugin-shell spawn |
| App.tsx 拆分引入回归 | UI 行为异常 | 每步拆分后完整手动验证 + typecheck |
| 分页加载与虚拟滚动冲突 | 列表闪烁/跳动 | 使用 cursor-based 分页而非 offset |
| CancellationToken 跨线程传递 | 编译错误 | 使用 tokio_util 标准方案 |

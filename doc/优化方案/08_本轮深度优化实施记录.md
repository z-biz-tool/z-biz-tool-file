## 2. 新发现的严重缺陷：预览与实际结果对不上（台账没记）

### 2.1 现象

批量重命名是**带预览**的功能（见 `doc/优化方案/01_现状审计与问题清单.md:180`）。
但预览表里算出来的名字，和点「应用重命名」之后**真正落到磁盘上的名字不一样**。

实测 5 处不一致：

| # | 规则 | 前端预览 | 后端实际 | 后果 |
|---|---|---|---|---|
| 1 | `find_replace` 区分大小写 | 界面上有「区分大小写」开关，**默认关闭** | 后端签名里**没有**这个参数，永远区分大小写 | 用户取消勾选也没用 |
| 2 | `find_replace` 替换范围 | 只在**主名**里替换，扩展名保留 | 替换**整个文件名** | 搜索 `".txt"` 预览不动、实际把扩展名换了 |
| 3 | `prefix_suffix` 后缀位置 | 后缀加在**扩展名之前** | 后缀加在**扩展名之后** | `report.txt` → 实际得到 `report.txt_bak` |
| 4 | `auto_number` 步长 | 界面上有「步长」输入框，预览按它算 | 后端签名里**没有**这个参数 | 那个输入框是摆设 |
| 5 | `auto_number` 位数 | 界面帮助文字写着「不足位数用 0 补齐」，预览也补 | 后端**从来没补过** | 预览 `文件01.txt`，实际 `文件1.txt` |

**第 5 条在默认参数下就会触发**（默认 start=1 / step=1 / digits=2），
所以这不是边缘场景，是**每次用这个功能都会踩到**。

### 2.2 根因

前端 `src/components/BatchRename.tsx` 的 `computeNewName` 与后端
`src-tauri/src/commands.rs` 的 `rename_one` 是**两份各自演化的实现**，
中间**没有任何东西**保证它们一致 —— 而它们之间没有编译期联系。

### 2.3 修法

1. 后端把重命名规则抽成**纯函数** `compute_renamed_name(stem, extension, index, opts)`；
2. `RenameOptions` 补上 `step` / `digits` / `case_sensitive` 三个字段
   （`#[serde(default)]`，老客户端不发也能反序列化）；
3. `rename_one` 改走这个纯函数；
4. 前端把同样的规则抽到 `src/utils/renameModel.ts`；
5. **两侧共用一份夹具** `tests/fixtures/rename-cases.json`：
   - Rust 侧 `src-tauri/src/commands.rs` 的 `rename_contract_tests`；
   - TS 侧 `tests/renameContract.test.ts`。
   谁改了规则而另一侧没跟上，**先红的一定是错的那一侧**。

### 2.4 顺带解决的一个 Unicode 陷阱

Rust 标准库的 `replace` 只认完全相等，前端预览用的是 JS 正则的 `gi`。
实现 Rust 版"忽略大小写替换"时踩到 JS 的 Canonicalize 规则：

- **node 实测**（不是照着规范脑补）：
  `"report2024".replace(/REPORT/gi,"Doc")` → `"Doc2024"`；
  `"ß".replace(/ss/gi,"X")` → `"ß"`（**不匹配**）；
  `"École".replace(/école/gi,"X")` → `"X"`（匹配）；
  `"İstanbul".replace(/i̇stanbul/gi,"X")` → `"İstanbul"`（**不匹配**）。
- 于是后端的 `canonicalize()` 照着实现：ASCII 一律折成小写；非 ASCII 若 `toUpperCase()`
  恰好一个字符就用它，否则原样保留。**这三条期望值已写进夹具**，两侧都会验。

### 2.5 契约测试当场抓到我自己的 bug

写完纯函数后第一次跑，`every_case_matches_the_expected_name` **直接红了**：
`match_ignore_case_at` 里 `match (h.next(), n.next())` 的 `_ => return None` 分支
把「needle 已匹配完、haystack 还有剩余」这种**匹配成功**的情况当成了失败。
—— 这就是契约测试的价值：它不是"跑绿了就算"，是**能咬住**。

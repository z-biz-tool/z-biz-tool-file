# z-biz-tool-file

> 万能文件管理器 — 文件管理/媒体预览/播放/电子书阅读/全盘搜索

## 合并来源

| 原项目 | 模块 |
|--------|------|
| z-biz-tool-media-cos | 图片/视频预览 |
| z-biz-tool-ebook-reader | epub/txt阅读 |
| z-biz-tool-music-player-cos | 音频播放 |
| z-biz-tool-file-manager-cos | 文件管理 |
| (新增) | 全盘搜索 |

## 功能

- 文件树 + 目录浏览
- 双击图片 → 预览（PNG/JPG/GIF/WebP/HEIC/SVG...）
- 双击视频 → 播放（MP4/MOV/AVI/MKV...）
- 双击音乐 → 播放（播放列表/歌词/迷你模式）
- 双击epub → 阅读（书签/笔记/进度/夜间模式）
- 双击PDF → 阅读
- 全盘秒搜（文件名+内容搜索）

## 技术栈

- Electron
- Mac/Windows 双平台
